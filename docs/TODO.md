## todo音效
1. 独特雨声。
   除了每种材料一个声音，还可以区分：
- 金属屋顶：细碎、清脆，暴雨时变得密集。
- 木质屋顶：偏闷、温暖的敲击。
- 树冠：大片柔和沙沙声，偶尔出现较重的水滴。
- 水面：细小溅水，避免与金属一样都是“滴答”。
- 屋檐：零星较大的滴水，与连续雨声形成层次。
- 滴水石锥的滴水、熔岩声。
- 适配不同的雨。
- 竹林
- 尤其值得做的是雨停后的短暂余滴：雨声逐渐退去，暴露在雨中的树叶和屋檐还偶尔滴几下。这个细节能让天气变化有收尾。
2. 烟花声。
   可以围绕已有烟花效果设计不同声音：
- 小型爆裂：短促、清脆。
- 大型爆裂：更厚的低频冲击。
- 星形、苦力怕形：更集中的爆裂节奏。
- 闪烁效果：零散、持续的噼啪尾声。
- 近处和远处：近处能听清细节，远处以较闷的爆响为主。
- 烟花上升声，玩家使用烟花飞行声。
- 重点是让听觉跟着烟花的视觉变化走。染色不必影响声音，大小、形状、闪烁这些特征更容易让玩家理解。鞘翅推进用的烟花最好单独调节，避免频繁飞行时太吵。
3. 掉落物撞击地面的声音（暂定）。
   玩家扔出物品，第一次接触地面时，按“物品类别＋地面材质”播放轻微声音：
- 铁锭落石头：短促金属碰撞。
- 木棍落木板：干脆的轻敲。
- 羊毛、纸张：很轻的扑落。
- 物品落水：小水花。
- 要限制频率，尤其是刷怪塔、自动农场附近；已经静止的物品也不应不断发声。
4. 船的速度与水面接触声。
   起步时有划水声，速度提高后出现船头水花，转弯时水声偏向一侧，靠岸碰撞再根据岸边材料变化。木船、竹筏还可以有不同的轻微结构声。
水下音效，体现水下的沉闷感，看可不可以加音效滤镜。

5. 特定互动的机械质感。
   挑几种玩家经常使用的物体做精细增强，例如木门合页轻响、活板门撞框、铁链受力、拉弓时弓臂和弦的张力声。建议每个动作只加一两层，保留原版清晰的反馈，避免每次开门都变成长音效。
    火把燃烧木头声。

6. 从水中上岸后的短暂滴水。
   玩家或生物离开水面后，几秒内出现逐渐减少的滴水，落在木头、石头、水面上分别有不同音色。可以和材质雨声共用一套素材与规则。

## 开发阶段与优先级（2026-10-26）

开发顺序：雨天音效首版 → 发布后维护 → 烟花音效 → 雨后／屋檐余滴 → 再评估雨强系统与天气 Mod 联动。前文的其他音效和联动条目继续作为候选，不自动纳入首版。

### 阶段一：打磨并发布雨天音效首版

首版范围：背景雨声、现有七类材质雨声（木质、金属、玻璃、植被、沙砾、水面、柔软表面）、独立植物滴水，以及近／中／远雷声。石质、陶质、地面暂明确标为未提供专用素材，不阻碍首版发布。雨强系统和天气 Mod 联动放到首版之后考虑。

1. 确定素材与混音标准。
   - [ ] 确定背景雨声母带及变体，统一雨势、录音质感和响度。
   - [ ] 逐类筛选材质录音，保留表面特色，减少与背景雨幕重复的环境底声。
   - [ ] 调整近／中／远雷声的响度、力度与自然尾声。
   - [ ] 保留原始素材、来源与许可信息、加工及输出记录。
2. 逐层试听与打磨。
   - [ ] 按“背景单独 → 单种材质单独 → 背景＋材质 → 多材质＋雷声”顺序试听。
   - [ ] 处理重复感、起止断口、长片段叠加过密、背景掩盖材质细节等问题。
   - [ ] 以游戏内叠加效果决定默认响度，不要求所有素材单独播放时都很饱满。
3. 稳定播放逻辑与默认配置。
   - [ ] 调整触发密度、冷却、距离衰减和同时音源预算。
   - [ ] 检查移动、进屋、隔墙、停雨及混合材质场景的听感和性能。
   - [ ] 提供可直接使用的默认配置，GUI 用于个人偏好调整；明确标出缺素材的类别。
4. 验收与发布。
   - [ ] 完成最新代码的 Fabric、NeoForge 构建和相关自动检查。
   - [ ] 分别在游戏中验收室内外、水面、树叶、混合材质及雷雨场景。
   - [ ] 检查暂停／恢复、传送、换维度、资源重载、配置保存及静音／恢复后的音源清理。
   - [ ] 修复影响使用的问题，发布第一版测试版并收集实际反馈；构建通过与游戏验收分别记录。

### 阶段二：发布后维护，再开发烟花音效

- [ ] 优先处理首版反馈中的听感、性能与兼容性问题，稳定默认参数。
- [ ] 筛选已有 AI 烟花候选素材，确认可用后补充升空、爆裂和闪烁尾声。
- [ ] 区分近处与远处烟花听感，提供独立开关与音量。
- [ ] 鞘翅推进单独处理音量和触发频率，避免频繁使用时过吵。

优先烟花的原因：它能形成第二个容易感知的特色场景；可以围绕既有烟花事件增强声音，开发范围较清楚，也有现成候选素材可供筛选。

### 阶段三：雨后与屋檐余滴

- [ ] 复用材质分类及植物滴水资源，实现停雨后的树叶／屋檐短暂余滴。
- [ ] 让余滴频率逐渐降低，并验证表面遮挡、离开范围和换世界时的清理。

### 阶段四：重新评估雨强系统与天气联动

- [ ] 在音效基础和素材质量稳定后，单独确定雨强系统的需求与范围。
- [ ] 区分仅改变音效雨势、改变降雨画面，以及服务端真实天气与多人同步。
- [ ] 届时再核对天气 Mod API、光影及渲染兼容性；当前不新增依赖或开展适配。

暂缓雨强的原因：原版雨强稳定后通常到 1，持续的小／中／大雨需要额外变化规则；若画面也随之变化，还会涉及天气渲染、光影表现甚至多人同步。近期先确保首版核心听感，再增加独立音效场景。
